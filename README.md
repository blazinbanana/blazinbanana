### how i troubleshoot

```
1. reproduce  →  confirm the problem and its scope
2. observe    →  logs, metrics, resource usage, network
3. isolate    →  narrow down the layer (app / db / network / host)
4. fix        →  smallest change that solves it
5. document   →  write it up so it never costs time twice
```
